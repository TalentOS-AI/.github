# TalentOS

TalentOS is an AI agent startup building reusable agent skills, developer tooling and practical know-how for teams putting AI agents to work. TalentOS 是一家 AI Agent 初创公司，专注 Agent 技能、工具链与落地实践，也承接定制 Agent / 技能开发。

## Projects

- **[ai-agent-skills](https://github.com/TalentOS-AI/ai-agent-skills)** — Reusable Agent Skills distilled from AI Agents papers and repos (SKILL.md)
- **[claude-code-source-analysis](https://github.com/TalentOS-AI/claude-code-source-analysis)** — 拆解 Claude Code｜从51万行泄露源码中提炼架构、安全、多Agent设计逻辑，配合13张架构图和正反示例的中文实战手册
- **[AgentID](https://github.com/TalentOS-AI/AgentID)** — On-chain Agent Identity & Reputation Registry on Monad (Metropolis)
- **[metacog](https://github.com/TalentOS-AI/metacog)** — Metacognition Skill for Claude Code — 元认知系统，1 总控 + 8 认知技能
- **[OpenClaw-KnowHowHub](https://github.com/TalentOS-AI/OpenClaw-KnowHowHub)** — OpenClaw 的公共知识入口
